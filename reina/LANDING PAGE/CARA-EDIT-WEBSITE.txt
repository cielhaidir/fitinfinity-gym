================================================
CARA EDIT WEBSITE FIT INFINITY (fit-infinity-website.html)
================================================

File website ini cuma SATU file. Semua tulisan, foto, dan link
ada di dalamnya. Kamu tidak perlu bisa coding — cukup bisa
Ctrl+F (cari) dan mengetik.

------------------------------------------------
1. BUKA FILE-NYA UNTUK DIEDIT
------------------------------------------------
- Klik kanan file fit-infinity-website.html → Open with → Notepad.
  (Lebih nyaman: install "Visual Studio Code" gratis, teksnya berwarna.)
- Untuk MELIHAT hasilnya: double-click file-nya → terbuka di Chrome.
- Alur kerja: edit di Notepad → Save (Ctrl+S) → refresh Chrome (F5).

------------------------------------------------
2. MENGGANTI TULISAN
------------------------------------------------
- Tekan Ctrl+F, ketik tulisan yang mau diganti persis seperti
  yang terlihat di website. Contoh: cari "Forge Your"
- Ganti teksnya, JANGAN sentuh kode di sekelilingnya
  (yang berbentuk <tag> seperti <h1>, </p>, class="...").
- Aturan main: yang boleh diedit adalah teks DI ANTARA > dan <
  Contoh:  <b>Mini Hyrox</b>  →  <b>Fun Run 5K</b>

------------------------------------------------

------------------------------------------------
4. MENGGANTI JADWAL KELAS
------------------------------------------------
Cari: var SCHEDULE
Formatnya per hari:
  {d:'Senin', c:[{n:'Body Language', k:'Dance Fit', p:'Gerak, musik...'}]}
  d = hari · n = nama kelas · k = kategori · p = deskripsi singkat
Tambah kelas = tambah {n:'...', k:'...', p:'...'} dipisah koma.

------------------------------------------------
5. MENGGANTI FOTO
------------------------------------------------
Foto tertanam di dalam file sebagai kode panjang (data:image/...).
Cara paling gampang: minta Claude — "tolong ganti foto X dengan
foto ini" sambil connect folder/kirim fotonya. Claude yang proses
(kompres + pasang), kamu tinggal terima file barunya.

------------------------------------------------
6. MENAIKKAN KE INTERNET (DEPLOY)
------------------------------------------------
1. Buka https://app.netlify.com/drop  (daftar gratis sekali)
2. Ubah dulu nama file jadi: index.html
3. Drag & drop file-nya ke halaman itu → dapat link live
4. Setiap habis edit: drop ulang file terbaru ke site yang sama
   (menu Deploys → drag & drop)
